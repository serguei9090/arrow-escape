# Mathematical Shape Generation in Vector Escape

In **Vector Escape**, puzzle shape masks for **Boss** and **God** levels are generated completely through pure mathematics using geometry and parametric formulas—without requiring external PNG images or vector SVG files.

---

## Example: The `dogMask` Shape

The `dogMask(side)` shape is defined in [lib/data/level_generator/mask_generator_v2.dart](file:///i:/01-Master_Code/Apps/arrow-escape/lib/data/level_generator/mask_generator_v2.dart#L377-L384):

```dart
static Set<String> dogMask(int side) {
  final mask = <String>{}; 
  final s = side.toDouble();
  _ellipse(mask, side, s * 0.50, s * 0.48, s * 0.37, s * 0.36); // 1. Head Base
  _ellipse(mask, side, s * 0.18, s * 0.55, s * 0.14, s * 0.26); // 2. Left Floppy Ear
  _ellipse(mask, side, s * 0.82, s * 0.55, s * 0.14, s * 0.26); // 3. Right Floppy Ear
  _ellipse(mask, side, s * 0.50, s * 0.74, s * 0.18, s * 0.11); // 4. Lower Muzzle / Snout
  return _clean(mask, side);
}
```

### Mathematical Primitives Used

The shape is constructed by evaluating the 2D Ellipse inequality for every grid cell coordinate $(r, c)$:

$$\left( \frac{c + 0.5 - c_x}{r_x} \right)^2 + \left( \frac{r + 0.5 - c_y}{r_y} \right)^2 \le 1.0$$

Where $s$ is the dynamic grid size (e.g., $28 \times 28$):
- **Head Ellipse**: Center $(0.50s, 0.48s)$, Radii $(0.37s, 0.36s)$
- **Left Ear**: Center $(0.18s, 0.55s)$, Radii $(0.14s, 0.26s)$
- **Right Ear**: Center $(0.82s, 0.55s)$, Radii $(0.14s, 0.26s)$
- **Muzzle**: Center $(0.50s, 0.74s)$, Radii $(0.18s, 0.11s)$

## Key Advantages

1. **Resolution Independence**: The mathematical formula dynamically scales to any grid dimension ($10\times 10$ up to $40\times 40$) without distortion or pixelation.
2. **Zero File Assets**: Requires 0 MB of image assets.
3. **Guaranteed Solvability**: The arrows are placed reverse-chronologically inside the active `#` cells.
